# Compilador de Fortran

Proyecto final de Compiladores (D04, 2026-B), CUCEI, Universidad de Guadalajara.

Compilador para un subconjunto de Fortran 90 escrito en Python, con IDE propio.

Fases:

1. Análisis léxico
2. Tabla de símbolos
3. Análisis sintáctico
4. Análisis semántico
5. Generación de código intermedio (máquina de pila)
6. Ejecución del código objeto
